# نظام الفوترة — Invoicing System

تطبيق ويب عربي/إنكليزي لإدارة الأعمال: **الفوترة والمحاسبة والمخزون** مع أقسام متخصصة (المكتبات، الوكالات، التوزيع، المطاعم، الفنادق، العقارات…). يعمل **بالكامل داخل المتصفح** بلا خادم وبلا تسجيل دخول، وتبقى بياناتك على جهازك.

> نسخة شخصية لمستخدم واحد مشتقة من مشروع WASSILHA، مع إزالة تسجيل الدخول وإضافة **تصدير/استيراد البيانات** و**ربط تيليجرام**.

## المزايا

- الفواتير، المصروفات، التقارير، بيان الأرباح، الموظفون والرواتب، المخزون والدفعات وتواريخ الانتهاء.
- **المكتبات:** نقطة بيع سريعة، خدمات، مولّد أصناف، إعادة الطلب، الموردون، الصندوق اليومي.
- **الوكالات:** اتفاقيات الوكالة، الشحنات وتكلفة الوصول (Landed cost)، الأهداف والمكافآت، مستحقات الشركة الموردة.
- التوزيع، المطاعم والحجوزات، الفنادق، العقارات، المشتريات، الكتالوج، الخريطة، المهام، التقويم، المستندات، الحاسبة.
- مساعد ذكاء اصطناعي يعمل بمفتاحك الخاص (لا يمر بأي خادم وسيط).
- واجهة عربية (RTL) وإنكليزية وإسبانية.

## ما الذي تغيّر عن النسخة الأصلية

| التغيير | التفصيل |
|---|---|
| بلا تسجيل دخول | يُنشأ مستخدم محلي واحد تلقائياً ويُفتح التطبيق مباشرة. |
| النسخ الاحتياطي | تصدير/استيراد ملف JSON واحد من **الإعدادات ← النسخ الاحتياطي** (وأيقونة التنزيل في الشريط الجانبي). يشمل الصور والفيديو اختيارياً، ويستثني المفاتيح السرية افتراضياً. يقبل أيضاً ملفات النسخة القديمة. |
| تيليجرام | تقارير وتنبيهات إلى بوتك (انظر أدناه). |
| نماذج الذكاء الاصطناعي | تحديث النماذج الافتراضية والروابط الرسمية (انظر أدناه). |
| مفاتيح التخزين | بادئة جديدة `invsys_` حتى لا تتداخل بياناتك مع النسخة الأصلية إن نُشرتا على نفس نطاق github.io. |

## الذكاء الاصطناعي

أدخل مفتاحك في **نماذج الذكاء الاصطناعي** أو الإعدادات، ثم اضغط «اختبار». يطلب التطبيق قائمة النماذج الحية من المزوّد ويختار نموذجاً موجوداً فعلاً.

| المزوّد | رابط المفتاح الرسمي | النموذج الافتراضي |
|---|---|---|
| Google Gemini | https://aistudio.google.com/app/apikey | `gemini-3.5-flash-lite` (ثم `gemini-3.8-flash`) |
| GroqCloud | https://console.groq.com/keys | `openai/gpt-oss-120b` |
| Cerebras | https://cloud.cerebras.ai | `gpt-oss-120b` |
| OpenRouter | https://openrouter.ai/keys | `meta-llama/llama-3.3-70b-instruct:free` |
| xAI Grok | https://console.x.ai | يُختار من القائمة |

> روجعت هذه النماذج مع وثائق المزوّدين في نوفمبر 2026: أُوقف `llama-3.3-70b-versatile` في Groq بتاريخ 16 أغسطس 2026، و`gemini-2.5-flash` مجدول للإيقاف في 1 ديسمبر 2026، و`llama-3.3-70b` في Cerebras أُعلن إيقافه. النماذج تتبدّل كثيراً، لذا يعتمد التطبيق على القائمة الحية، ويمكنك اختيار نموذج آخر بعد الاختبار.

## ربط تيليجرام

1. أنشئ بوتاً (أو استخدم بوتاً جاهزاً) من [@BotFather](https://t.me/BotFather) وانسخ **الرمز**.
2. افتح البوت في تيليجرام، اضغط **Start** وأرسل أي رسالة.
3. في التطبيق: **الإعدادات ← تيليجرام**، الصق الرمز واضغط **اتصال** (يكتشف رقم المحادثة تلقائياً)، ثم **رسالة تجربة**.

ما يمكن إرساله: **الصندوق اليومي** و**نقص المخزون** (المكتبات)، **ملخص الوكالات** و**الشحنات** (الوكالات)، وتنبيهات يومية اختيارية (نقص المخزون، شحنات قريبة أو متأخرة، عقود وكالات تنتهي).

حدود يجب معرفتها:

- الإرسال يتم من المتصفح، فالتنبيهات التلقائية تعمل **عند فتح التطبيق** (مرة يومياً).
- الرمز محفوظ في هذا المتصفح فقط. إن شككت بتسريبه فجدّده من @BotFather.
- الرد التلقائي على العملاء (24 ساعة) يحتاج خادماً دائم التشغيل، وهو خارج نطاق هذه النسخة.

## النشر على GitHub Pages

1. ارفع المشروع إلى مستودع جديد على GitHub.
2. **Settings ← Pages ← Source: GitHub Actions**.
3. أي دفع (push) إلى الفرع `main` يشغّل `deploy.yml` وينشر التطبيق على `https://<user>.github.io/<repo>/`.

المسارات تعمل بنمط Hash (`#/`) فلا مشكلة مع تحديث الصفحة على GitHub Pages.

## الخصوصية والقيود

- كل البيانات في `localStorage` و`IndexedDB` لمتصفح واحد: لا مزامنة بين الأجهزة. **صدّر نسخة احتياطية بانتظام** (يذكّرك التطبيق أسبوعياً).
- سعة `localStorage` نحو 5 ميغابايت؛ الصور والفيديو تُحفظ في IndexedDB ولا تخضع لهذا الحد.
- لا تتوفر الميزات التي تحتاج خادماً (محادثة حية بين أجهزة، مكالمات بين مستخدمين).
- لا تشارك ملف النسخة الاحتياطية إن أدرجت فيه المفاتيح السرية.
